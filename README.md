# Matriz Final de Clasificación Taxonómica & Función Ecológica (UNISANGIL 2026-2)

Este proyecto corresponde a la plataforma web de monitoreo fitosanitario y biofertilización para el programa de Ingeniería Agrícola de la Fundación Universitaria de San Gil (UNISANGIL - Sede Yopal).

## 📁 Estructura del Repositorio

- `docs/`: Documentación del proyecto.
- `imagenes/`: Fotografías y gráficos de las muestras recopiladas.
- `src/`: Código fuente principal de la aplicación web (`index.html`).
- `videos/`: Evidencia audiovisual del proceso de muestreo.
- `index.html`: Aplicación web interactiva publicada a través de GitHub Pages.
- `GUIA_PARA_SUBIR_A_GITHUB.txt`: Instrucciones paso a paso para la publicación y gestión en GitHub.

## 🚀 Despliegue en GitHub Pages

1. Sube todo el contenido de este repositorio a GitHub.
2. Ve a **Settings** -> **Pages**.
3. En **Branch**, selecciona `main` o `principal` y guarda.
4. Tu sitio estará disponible públicamente.
